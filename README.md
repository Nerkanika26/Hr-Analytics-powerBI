HR Analytics Dashboard using Power BI

A Power BI dashboard created to analyze employee data and present HR insights through interactive visualizations.

🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

📊 Dashboard Pages

- Page 1: HR Overview
- Page 2: Employee Demographics & Workforce Analysis
- Page 3: Employee Salary & Department Analysis

- Analyze employee data
- Understand workforce distribution

- Create an interactive HR dashboard
- Present data-driven insights visually

🔍 Key Features

- KPI cards
- Interactive charts
- Employee analysis
- Department analysis
- Salary analysis
- Clean dashboard design
